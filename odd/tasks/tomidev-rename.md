# tomidev-rename

Full rebrand of the fork from gentle-shell / gentle-pi to tomidev. Clean cut (no old-name
aliases), except one-time data migration and dual-read of persisted session ids. No commits
unless the user asks (AGENTS.md). Work starts only after the user finishes his own task
("punto 1": banner ASCII logo, sidebar label, pi.image) and says so.

## Specs

- S1 Scope: "Completo" — rename user-visible and internal surfaces (bin, commands, home,
  env vars, marker files, schema ids, Symbol.for keys, channels, User-Agent, text, docs).
- S2 Names: "tomidev, /td:*" — bin `tomidev`, slash commands `/td:<name>`, home `~/.tomidev`.
- S3 Aliases: "No, corte limpio" — old bin `gentle-shell` and `/gentle:*` commands are removed,
  not kept as aliases.
- S4 Isolation: "Branch en este mismo dir" — work on a branch in this working tree, after the
  user's punto 1 is done.
- S5 gentle-ai: "Renombrar y adaptar el setup" — the npm package is renamed too; the setup flow
  must stop depending on the gentle-ai binary's hardcoded `npm:gentle-pi`,
  `GENTLE_PI_CONFIG_HOME` and `~/.pi/gentle-ai`.
- S6 Home data: "Migrar una vez (recomendado)", refined by "Copiar una vez (recomendado)" — on
  first launch, data in `~/.gentle-shell` (auth, sessions, settings, profiles, config) is copied
  once to `~/.tomidev`; `~/.gentle-shell` stays intact (the user deletes it when he wants); no
  alias afterwards (tomidev never reads `~/.gentle-shell` again after the copy).
- S7 Sessions: "Leer ambos, escribir nuevo" — persisted ids such as
  `gentle-pi.session-profile/v1` are still read; new writes use `tomidev.*`.
- S8 Commits: "sin commitear" — leave changes uncommitted.
- S10 Setup (T4): companions "gentle-engram, pi-web-access, pi-btw"; MCP "Dejar MCP
  habilitado" (never write `-builtin:mcp`); installer + upgrade: "Sí, dentro de T4" (preflight,
  postinstall and main channel stop requiring/building gentle-ai).
- S11 RDD: "vamos analizar si lo quitamos o lo adaptamos despues de analizar el system prompt,
  los agentes builtin y las skills builtin" — leave RDD tools as they are in this stage (they
  degrade to package-binary-missing without the binary).
- S12 Distribution: "Desde tu repo Git (recomendado)", owner "TommiL90" — installer, upgrade and
  pi-update install from `git:github.com/TommiL90/tomidev-shell` (repo name assumed = local
  repo name, one constant), never from the npm registry name `tomidev` (unowned). The startup
  update prompt is removed (earlier decision: "Update prompt al arrancar" in the extras to
  remove). No remote creation or push.
- S9 Keep untouched: names owned by other projects that this fork still consumes —
  `gentle-engram` / `ENGRAM_*`, `PI_CODING_AGENT_DIR` and other `PI_*`, `contracts/`
  (digest-pinned upstream mirror), upstream release URLs.
